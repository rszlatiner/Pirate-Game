# The Curse of the Missing Hat

A humorous pirate choose-your-own-adventure for a creative writing class.
Single self-contained web page: open `index.html`, or host the folder on any static host (Vercel, Netlify, GitHub Pages).

- 8 endings, items, dice-roll choices and a Rewind button
- 5 Captain's Log writing prompts (students can copy their log into a document)
- Progress saved in the student's own browser
