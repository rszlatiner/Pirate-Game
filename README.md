# The Curse of the Missing Hat

A humorous pirate choose-your-own-adventure for a creative writing class.
Single self-contained web page: open `index.html`, or host the folder on any static host (Vercel, Netlify, GitHub Pages).

## Features
- **10 endings**, items, dice-roll choices and a Rewind button
- **Crew hub:** four crew members must be visited before sailing; every side character has a job in the plot
- **8 allies** to befriend (befriend them all to unlock the Grand Alliance ending)
- **Doubloon leaderboard** (stored per device) with score breakdown and copyable score card
- **Saved journeys:** save and continue adventures, view completed routes, and back up / import with a code
- **5 Captain's Log writing prompts** (students can copy their log into a document)
- Progress saved in the student's own browser
